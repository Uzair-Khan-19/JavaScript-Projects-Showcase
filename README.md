# JavaScript Projects Showcase

A collection of web projects I built while learning and practicing JavaScript. The repository contains several individual projects, all accessible through a single home page.

The projects focus on JavaScript fundamentals, DOM manipulation, event handling, application logic, and building interactive web experiences.

## Live Demo 
Link: https://uzair-khan-19.github.io/JavaScript-Projects-Showcase/
## Projects

### 1. To-Do App

A simple task management application built with JavaScript.

**Features:**

* Add new tasks
* Delete tasks
* Manage tasks dynamically
* DOM manipulation
* Event handling

**Technologies:** HTML, CSS, JavaScript

---

### 2. Calculator

A functional calculator created to practice JavaScript logic, functions, events, and DOM manipulation.

**Features:**

* Basic arithmetic operations
* Interactive buttons
* Dynamic display
* Event handling
* JavaScript-based calculations

**Technologies:** HTML, CSS, JavaScript

---

### 3. DOM Projects

A collection of small projects created while learning and practicing DOM manipulation.

These projects helped me understand how JavaScript interacts with HTML elements and how dynamic changes can be made to a web page.

**Concepts practiced:**

* Selecting HTML elements
* Modifying text and styles
* Adding and removing classes
* Event listeners
* Creating elements dynamically
* Updating the DOM

**Technologies:** HTML, CSS, JavaScript

---

### 4. Heads and Tails Game

A simple coin-flip game built using JavaScript.

**Features:**

* Heads and Tails selection
* Random computer choice
* Result calculation
* Interactive user interface

**Technologies:** HTML, CSS, JavaScript

---

### 5. Rock Paper Scissors

A browser-based Rock Paper Scissors game where the player competes against the computer.

**Features:**

* Player versus computer gameplay
* Random computer moves
* Win, loss, and tie detection
* Score tracking
* Interactive controls

**Technologies:** HTML, CSS, JavaScript

---

### 6. E-Commerce Cart

An Amazon-inspired e-commerce cart project built to practice more advanced JavaScript concepts.

**Features:**

* Product listing
* Add products to cart
* Update product quantity
* Remove products from cart
* Cart state management
* Dynamic price calculation
* DOM manipulation
* JavaScript modules

**Technologies:** HTML, CSS, JavaScript
